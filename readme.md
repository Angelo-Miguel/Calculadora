# Calculadora

Uma calculadora simples feita com HTML, CSS e JavaScript.

## Funcionalidades

- Operações básicas: soma, subtração, multiplicação, divisão
- Potenciação (`^`)
- Raiz quadrada (`√`)
- Limpar visor (`AC`)
- Limpar dígito (`⌫`)
- Suporte a ponto decimal

## Estrutura do Projeto

```
.

├──src/
│  ├──css/
│  │    └── style.css   # Estilos personalizados.
│  └── js/
│       └── script.js   # Lógica das operações e interação com os botões.
├── index.html          # Interface principal da calculadora.
└── LICENSE
```


## Como usar

1. Abra o arquivo [`index.html`](https://angelo-miguel.github.io/Calculadora/) em seu navegador.
2. Utilize os botões para realizar cálculos.
